About these controls

These are the parameters in your saved Inochi rig. Changes appear immediately and stay in this browser until you reset them. Use Save expression to keep a portable JSON copy.

Both eyelid controls use 1 for open and 0 for closed. Eye movement uses positive Y for up. Some extreme combinations can show the same skin seams or distortions as the original rig.
